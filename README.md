# 🛒 Amazon Sales Analysis | Power BI Dashboard

## 📌 Project Overview

Amazon Sales Analysis is a data analytics project developed using Microsoft Power BI to explore sales performance and identify meaningful business insights through interactive data visualization.

The project presents sales-related metrics and visual reports to help understand revenue patterns, product performance, and sales distribution across different business dimensions.

## 📊 Dashboard Overview

The Power BI report includes visualizations designed to explore:

- Sales performance and key metrics
- Revenue trends and comparisons
- Product and category performance
- Sales distribution across different dimensions
- Business performance indicators
- Interactive filtering and data exploration

## 🔍 Key Analysis Areas

- Overall sales performance
- Revenue trends and patterns
- Product performance analysis
- Sales distribution and comparisons
- Category-level analysis
- Identification of business trends
- KPI monitoring and reporting

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file in Power BI Desktop.
4. Explore the available report pages and interactive visualizations.

If the report requires an external data source, configure the appropriate connection before refreshing the data.
